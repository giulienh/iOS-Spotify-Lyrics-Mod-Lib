# iOS Spotify Lyrics Mod Lib

Web bundle for the iOS Spotify lyrics mod (derived from Spicy Lyrics, AGPL-3.0). The mod downloads
`manifest.json`, verifies every file against its SHA-256 hash and installs the bundle for the next lyrics view.

Only the interpreted web layer (`index.html`, `app.js`, `styles.css`) is delivered here. No native code is loaded.
